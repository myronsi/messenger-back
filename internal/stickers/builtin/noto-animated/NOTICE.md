# Noto Animated Emoji

The `.webp` files in this folder are animated emoji from [Noto Emoji Animation](https://googlefonts.github.io/noto-emoji-animation/) by Google, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). They are the unchanged 512 px animated WebP files, renamed to their code points.

The files in `panel/` are changed: the first frame of each animation, scaled to 128 px and saved as a still WebP, for sticker pickers.
